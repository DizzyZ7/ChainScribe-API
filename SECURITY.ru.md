# Политика безопасности

[English version](SECURITY.md)

Не публикуйте сведения о предполагаемых уязвимостях в открытых Issues. Используйте механизм приватных уведомлений безопасности GitHub для этого репозитория и укажите затронутый коммит, шаги воспроизведения, возможное влияние и предлагаемый способ устранения.

Никогда не прикладывайте реальные production-учетные данные, токены, приватные ключи или персональные данные.

Поддерживается только последний коммит ветки по умолчанию. Перед передачей диагностической информации замените любые учетные данные, которые могли попасть в отчет.
